#COVID Data Exploration & Tableau Dashboard
This project uses SQL Server to explore global COVID data and Tableau Public for visualizing infection rates, deaths and changes over time.

## Tools
- Microsoft SQL Server
- Tableau Public
- Microsoft Excel
